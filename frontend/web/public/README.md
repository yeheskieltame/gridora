# Gridora brand assets

Chosen logo = **Option B** (continuous coral "G" on black, grid texture + glow nodes).

| File | Use |
|---|---|
| `gridora-logo.svg` / `.png` (1024) | Full app icon, black rounded tile. DoraHacks BUIDL logo = `gridora-logo-480.png`. |
| `gridora-logo-480.png` | 480×480 submission logo (<2MB). |
| `gridora-mark.svg` / `.png` | Transparent "G" only (no tile), use inside the dark UI / header / wordmark. |

`app/icon.png` + `app/apple-icon.png` are auto-served by Next.js as favicon / Apple touch icon (no import needed).

Brand colors: coral `#D97757`, light coral `#F2AE80`, deep clay `#A24E32`, cream `#F0EEE6`, near-black `#0A0A0A`.
